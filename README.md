# Python_Projects
The repository mainly has simple python mini projects,
1)Rock Paper Scissor Game:It basically considers user's input and predefined input(computer input) and shows the result accordingly
Conditions as such:
Winning rules of the game ROCK PAPER SCISSOR are-:
      #Rock vs Paper -> Paper wins 
      #Rock vs Scissors -> Rock wins 
      #Paper vs Scissors -> Scissors wins 

2)Perfect Number Guessing Game: It is a simple interactive program where the computer randomly selects a number within a given range, and the player tries to guess it within a limited number of attempts.
Condition guess against random number:
->If the guess is too low, the program displays "The number guessed is low.
->If the guess is too high, the program displays "The number guessed is high.
->If the guess is correct, the program displays "The number guessed is right, and the game ends.
